# Media Metadata Agent 参数使用指南

本文档详细说明了 `batch_scraper.py`（批量处理脚本）和 `src.app.cli`（单任务命令行接口）的参数功能、优先级及常见组合用法。

## 1. 批量处理脚本 (batch_scraper.py)

用于批量扫描目录，自动识别、整理和刮削影视资源。

### 1.1 核心操作模式

| 模式 | 参数 | 描述 |
| :--- | :--- | :--- |
| **原地整理 (默认)** | (无) | 直接在输入目录内进行重命名和整理，不移动文件位置。 |
| **移动模式** | `--output <DIR>` | 将整理后的文件**移动**到指定输出目录。 |
| **复制模式** | `--output <DIR> --copy` | 将整理后的文件**复制**到指定输出目录，保留原文件。 |
| **强制原地** | `--inplace` | 即使指定了 output 也强制使用原地模式（常用于搭配其他脚本）。 |
| **多目录模式** | `--multi` | 扫描输入目录下的**所有子文件夹**，每个子文件夹视为一个独立的影视项目；同时处理根目录下的散乱视频文件。 |

### 1.2 功能增强参数

#### 1.2.1 `--use-local-nfo`
- **功能**: 从本地 NFO 文件中提取 `<tmdbid>`。
- **工作原理**:
  - **TV 模式**: 优先查找 `tvshow.nfo`，其次查找任意 `*.nfo`。
  - **Movie 模式**: 
    1. **严格匹配**: 优先查找文件名包含文件夹名的 `.nfo` 文件（防止误读取）。
    2. **回退匹配**: 如果没找到，则查找任意 `.nfo` 文件。
- **优先级**: 高于文件名解析搜索，低于 `--tmdb-id`。

#### 1.2.2 `--type <movie|tv>`
- **功能**: 强制指定媒体类型。
- **默认行为**: 默认为 `tv`（剧集）。
- **影响**: 
  - 决定调用 TMDB 的 Movie API 还是 TV API。
  - 影响 `--use-local-nfo` 的搜索逻辑（见上条）。
  - 影响文件整理结构（电影通常为单文件或简单目录，剧集有 Season 目录）。

#### 1.2.3 `--tmdb-id <ID>`
- **功能**: 直接指定 TMDB ID，跳过搜索步骤。
- **限制**: 通常仅在处理**单个**目录（非 `--multi`）且为**原地**模式时有效。

#### 1.2.4 `--extra-images`
- **功能**: 创建 `Extra` 子目录，下载更多类型的图片（特定海报、Fanart等）。

### 1.3 常见参数组合及场景

#### 1.3.1 整理单个剧集目录 (原地)
```bash
python batch_scraper.py "/Media/TV/Breaking Bad"
```
*   **行为**: 识别 "/Media/TV/Breaking Bad" 内的视频，在当前目录重命名并生成元数据。

#### 1.3.2 整理单个电影目录 (原地) + 强制类型
```bash
python batch_scraper.py "/Media/Movies/Inception" --type movie
```
*   **行为**: 强制按电影模式处理该目录。

#### 1.3.3 批量整理剧集库 (多目录模式)
```bash
python batch_scraper.py "/Media/Downloads/Completed_TV" --multi
```
*   **行为**: 扫描 `Completed_TV` 下的每个子文件夹（如 `Show A`, `Show B`），分别作为剧集处理。同时处理 `Completed_TV` 根目录下的散乱视频文件。

#### 1.3.4 批量整理拥有现有 NFO 的资料库 (精准匹配)
```bash
python batch_scraper.py "/Media/Existing_Library" --multi --use-local-nfo
```
*   **行为**: 扫描所有子目录，优先读取每个子目录下的 NFO 文件中的 ID 进行精确匹配刮削。适用于迁移或刷新现有媒体库。

#### 1.3.5 批量整理动画电影 (拥有 NFO)
```bash
python batch_scraper.py "/Media/Anime_Movies" --multi --type movie --use-local-nfo
```
*   **行为**: 
    1. 扫描子目录。
    2. 针对每个子目录，先尝试严格匹配（寻找文件名包含文件夹名的 NFO）提取 ID。
    3. 使用 Movie API 获取数据并整理。
    *   **适用场景**: 复杂的动画电影文件夹，防止错误读取到其他无关 NFO。

## 2. 单任务命令行 (src.app.cli)

用于对明确的单个目标（名称或 ID）进行刮削，功能更精细，支持详细的语言和搜索配置。

### 2.1 核心参数

| 参数 | 简写 | 描述 |
| :--- | :--- | :--- |
| `query` | (位置参数) | 搜索关键词（剧名或电影名）。如果指定了 ID 参数可省略。 |
| `--tmdb-id` | | 指定 TMDB ID（精确匹配）。 |
| `--omdb-id` | | 指定 OMDB (IMDb) ID。 |
| `--type` | `-t` | 媒体类型 (`movie` 或 `tv`)。默认自动检测（先 TV 后 Movie）。 |
| `--output` | `-o` | 输出根目录。默认为 `./output`。 |

### 2.2 语言与翻译控制

#### 2.2.1 `--lang <code/zh-CN>`
- **功能**: 指定 TMDB 请求的首选语言。
- **选项**: `zh-CN` (默认), `zh-TW`, `en-US`。

#### 2.2.2 `--translate`
- **功能**: 启用 LLM 翻译补全。
- **行为**: 当 TMDB 返回的字段（简介、Tagline 等）在首选语言下为空时，调用 LLM 将其翻译为首选语言。

#### 2.2.3 `--translate-tags` / `--no-translate-tags`
- **功能**: 是否将流派、关键词等标签翻译为中文。
- **默认**: 开启 (`--translate-tags`)。

### 2.3 搜索增强

#### 2.3.1 `--aid-search`
- **功能**: 辅助搜索。
- **行为**: 当 TMDB 内部搜索无结果时，尝试使用 Google Search API（需配置）查找对应的 TMDB ID。适用于非标准命名或别名搜索。

### 2.4 常见组合示例

#### 2.4.1 基础搜索刮削
```bash
python -m src.app.cli "The Dark Knight" --type movie
```

#### 2.4.2 指定 ID 精确刮削 + 翻译补全
```bash
python -m src.app.cli --tmdb-id 1399 --type tv --translate --output "/Media/TV"
```
*   **行为**: 获取《权力的游戏》(ID 1399) 的元数据，如果中文简介缺失，自动翻译英文简介。

#### 2.4.3 强力搜索模式 (解决搜不到的问题)
```bash
python -m src.app.cli "小众文艺片" --type movie --aid-search --verbose
```
*   **行为**: 开启 Google 辅助搜索，并打印详细日志以便排错。

## 3. 优先级总结

1.  **ID 优于 名称**: 无论在哪个脚本，只要提供了 `--tmdb-id` (或从 NFO 提取到了 ID)，都会跳过名称搜索，直接获取元数据。这是一个"强锚点"。
2.  **强制类型 优于 自动检测**: 指定 `--type` 后，系统不会尝试另一种类型。
3.  **Local NFO 优于 文件名**: 在 `batch_scraper` 中，启用 `--use-local-nfo` 后，文件名中的信息（年份、拼写）重要性降低，以 ID 为准。

## 4. 目录结构说明

系统生成的标准结构如下：

**Movie:**
```
Output_Dir/
  └── 电影标题 (年份)/
      ├── 电影标题 (年份).nfo
      ├── 电影标题 (年份).mkv
      └── images/ ...
```

**TV:**
```
Output_Dir/
  └── 剧集标题 (年份)/
      ├── tvshow.nfo
      ├── images/ ...
      ├── Season 01/
      │   ├── 剧集标题 - S01E01 - 单集标题.mkv
      │   └── ...
```
